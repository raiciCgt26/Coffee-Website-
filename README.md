# Coffee-Website ☕
![Pagina Principal](Captura%20de%20pantalla%202024-10-23%20150423.png)
Un sitio web moderno y elegante para una cafetería de especialidad, diseñado para ofrecer una experiencia visual inmersiva. El proyecto aplica principios de diseño **"Mobile First"** para garantizar una navegación fluida en cualquier dispositivo.

---

## 🛠️ Tecnologías

* **HTML5 Semántico:** Estructura clara y accesible para SEO.
* **CSS3 (Flexbox/Grid):** Maquetación moderna y flexible.
* **JavaScript Vanilla:** Interactividad pura sin librerías externas.

---

## ✨ Características clave

### 📱 Responsive Design
Adaptabilidad total, garantizando que el sitio se vea perfecto desde pequeños **smartphones** hasta monitores **4K**.

### 🖱️ Interactividad
* **Menú desplegable animado:** Una interfaz intuitiva que mejora la experiencia de usuario en móviles.
* **Efectos de Scroll Reveal:** Animaciones de entrada que se activan al desplazar la página, aportando dinamismo.

### ⚡ Optimización
* **Carga rápida:** Manejo eficiente de imágenes para reducir tiempos de espera.
* **Tipografías personalizadas:** Integración de fuentes que refuerzan la identidad visual de la marca.
